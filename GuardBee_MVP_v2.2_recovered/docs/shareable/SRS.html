GuardBee Software Requirements Specification

Scope: Synthetic suspicious-login investigation with deterministic risk, TF-IDF policy retrieval, optional Nebius/Nemotron explanation, and one human-approved simulated outcome.

Interfaces

  • Streamlit dashboard
  • Validated JSON incident and policy files
  • Optional OpenAI-compatible Nebius Token Factory client
  • Temporary Streamlit session audit state

Functional requirements

IDRequirement
FR-01Validate non-empty synthetic incident and policy data before use.
FR-02Show event timeline and deterministic risk evidence.
FR-03Retrieve only threshold-qualified policy matches locally.
FR-04Require current event and retrieved policy IDs in a usable AI report.
FR-05Record one simulated decision per validated report in session state.

Constraints

No real accounts, logs, automatic remediation, durable database, or verified live model result are included. Live inference requires an authorized account, model availability, network access, and quota.
